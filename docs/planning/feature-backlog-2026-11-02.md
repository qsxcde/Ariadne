# 功能点全量清单（2026-11-02）

> 用途：把「智能论文助手」从规划拆成可逐项核对的 backlog。
> 目标用户：个人研究生；进度以阅读进度为主；先 M0 数据模型，再 M1 AI。
> 状态说明：**已有** = 当前代码可用；**部分** = 有基础但未形成闭环；**待做** = 尚未实现；**不做** = 明确移出范围。
> 关联：[产品规划](product-plan-2026-11-02.md)、[M0 设计稿](m0-paper-model-2026-11-02.md)、[现状分析](../analysis/status-2026-11-02.md)

## 1. 已有能力（不重复建设）

| 能力 | 现状 | 说明 |
|---|---|---|
| PDF 上传 + 异步摄取 | 已有 | 202 + job + 状态机 + 启动恢复；单文件上传 |

| SSE 流式问答 | 已有 | status/token/sources/done + 心跳；单会话 |

| 契约与 CI | 已有 | OpenAPI → TS 类型、契约 diff、ruff/mypy/pytest |

## 5. 明确不做

- 不做完整参考文献管理器（Zotero 替代品）。
- 不爬取付费墙后的全文。
- 不做团队协作、共享笔记、多租户。
- 不做移动端原生 App（PC Web 优先）。
- 不对全库论文预生成摘要；按需生成并缓存。
- 不输出没有原文依据的「总结」。

## 8. 一句话优先级

**先把「论文能独立存在、阅读进度能持久化、笔记能锚定原文」做出来（M0）；再把「读得快、读得懂」做出来（M1）；最后才做「跨论文、跟进、导出」（M2+）。**
