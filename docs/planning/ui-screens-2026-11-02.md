# 界面清单与信息架构（2026-11-02）

> 状态：规划稿，尚未实施。
> 目标：在「个人研究生 + 阅读进度优先」的前提下，用尽量少的页面承载完整功能。
> 关联：[产品规划](product-plan-2026-11-02.md)、[功能点清单](feature-backlog-2026-11-02.md)、[M0 设计稿](m0-paper-model-2026-11-02.md)

## 0. 结论

**最小可用（M0 + M1）：5 个主页面 + 约 10 个面板/弹窗。**

**完整产品（M0–M4）：7 个主页面 + 约 14 个面板/弹窗。**

其中：

- 3 个主页面已有基础：登录、文献库、阅读器。
- 4 个主页面需要新建：Today、Settings、Synthesis/Compare、Feed。
- 现有 Chat 页建议降级为「全屏问答」兼容入口；目标形态里，问答是阅读器和综合页里的侧栏，不再单独占一个一级页面。

## 1. 计数口径

| 类别 | 定义 | 是否计入「界面数」 |
|---|---|---|
| 主页面 | 有独立路由、可前进/后退、有一级导航入口 | 计入 |
| 详情页 | 从列表进入、有独立路由（如阅读器） | 计入 |
| 面板 / 抽屉 | 页面内的侧栏或抽屉，不改变路由 | 单独计数，不混入主页面 |
| 弹窗 / 气泡 | 导入、编辑、确认、选择器等 | 单独计数 |
| Tab / 空状态 / 加载态 | 同一页面内的状态 | 不计入 |
| 通用确认框 | 删除确认、离开确认 | 不计入 |

## 3. 目标信息架构

~~~text
/ (Today)
├── /library                    文献库
│   └── /collections/:id        集合视图（Library 的过滤状态）
├── /papers/:paperId            阅读器（含问答/笔记侧栏）
├── /collections/:id/synthesis  集合综合（问答 / 对比 / 综述矩阵）
├── /feed                       跟进（可选）
├── /settings                   设置
└── /login                      登录
~~~

一级导航最多 4 项：**Today / Library / Feed（可选）/ Settings**。阅读器和综合页是从列表进入的详情页，不占一级导航。

## 6. 关键页面布局

### 6.1 Today

~~~text
┌──────────────────────────────────────────────────────────┐
│ Today          [本周 3/5 篇]        [搜索]  [导入论文]   │
├───────────────────────────┬──────────────────────────────┤
│ 继续阅读                   │ 阅读队列                     │
│ [论文卡 + 进度条 + 续读]   │ 1. 论文 A  [在读] [高]       │
│                           │ 2. 论文 B  [待读] [中]       │
├───────────────────────────┼──────────────────────────────┤
│ 本周复盘                   │ 开放问题 / 最近笔记           │
│ 读完 3 篇 · 笔记 12 条     │ [问题] [笔记]                │
└───────────────────────────┴──────────────────────────────┘
~~~

要点：Today 是「行动页」，不做全量列表；全量列表在 Library。

### 6.2 Library

~~~text
┌ sidebar ┬ 过滤器 ─────────────┬ 论文列表 ─────────────────┐
│ Today   │ 状态: 全部/在读/待读 │ [ ] 论文卡 + 作者 + 年份   │
│ Library │ 集合: ...            │     状态 / 进度 / 标签     │
│ Feed    │ 标签: ...            │ [ ] ...                    │
│ Settings│ 搜索: [          ]   │                            │
└─────────┴──────────────────────┴────────────────────────────┘
~~~

要点：列表行以 paper 为单位，不按 session；支持批量选择加入集合/导出。

### 6.3 Reader

~~~text
┌ 大纲 ┬ 正文 / PDF ──────────────────┬ 右侧栏 ─────────────┐
│ 1 引言│ 论文内容 + 高亮 + 批注锚点   │ [问答] [笔记] [来源] │
│ 2 方法│                              │ 对话 / 笔记列表      │
│ 3 实验│                              │ 引用可回跳           │
└───────┴──────────────────────────────┴─────────────────────┘
~~~

要点：阅读器是产品中心；问答不是独立页面，而是右侧栏的一个 Tab。顶部显示进度条与「标记已读」。

### 6.4 Synthesis / Compare

~~~text
┌ 集合选择 ┬ [问答] [对比表] [综述矩阵] ───────────────────┐
│ 论文 A   │ 问答：跨论文回答，引用带 paper 标识             │
│ 论文 B   │ 对比：方法 / 数据集 / 指标 / 结论               │
│ 论文 C   │ 矩阵：可导出 Markdown / CSV                     │
└──────────┴────────────────────────────────────────────────┘
~~~

要点：只在集合范围使用；单篇问答留在 Reader。

### 6.5 Feed（可选）

~~~text
┌ 订阅 ┬ 新论文 ───────────────────────────────────────────┐
│ 关键词│ [论文卡] 为什么推给我：你读过 X，标了 Y           │
│ 作者  │ [保存到队列] [忽略] [立即读]                      │
│ venue │                                                  │
└───────┴──────────────────────────────────────────────────┘
~~~

要点：每条推荐必须有理由和可执行动作，避免变成第二个收件箱。

### 6.6 Settings

~~~text
┌ 设置导航 ──────┬ 内容 ──────────────────────────────────┐
│ 模型与 API     │ 表单 / 开关 / 测试连接                  │
│ 数据与备份     │ 数据目录、导出、恢复                    │
│ 隐私与本地模式 │ 本地模型、数据不上传                    │
│ 集成           │ Zotero / Notion                        │
│ 外观           │ 主题、字号                              │
└────────────────┴────────────────────────────────────────┘
~~~

## 7. 导航与交互原则

1. **一级导航不超过 4 项**：Today / Library / Feed / Settings。阅读器和综合页是详情页。
2. **阅读器是中心**：问答、笔记、来源都在阅读器右侧栏，不跳页。
3. **Library 管资产，Today 管行动**：避免在 Library 里堆队列和统计。
4. **面板优先于弹窗**：笔记、问答、来源用侧栏/抽屉；只有导入、编辑元数据、选择器用弹窗。
5. **移动端不单独做界面**：PC Web 优先，窄屏只做可用性降级，不新增页面。

|---|---|---|---|

| M1 | 5：+ Today | O7、O8（2 个） | 5 页 + 10 面板 |
| M2 | 6：+ Synthesis/Compare | O9、O11（2 个） | 6 页 + 12 面板 |

## 9. 验收口径

- 5 个核心页面（Login / Today / Library / Reader / Settings）可完成「导入 → 打开 → 标记在读 → 高亮笔记 → 续读 → 查看队列」全流程。
- 任何 AI 输出都能从页面回到原文，不需要打开新窗口。
- 一级导航不超过 4 项；阅读器内不跳页即可完成问答/笔记/来源查看。
- 空状态、加载态、失败态在同一页面内处理，不新增页面。
- 窄屏只做布局降级，不新增移动端页面。
